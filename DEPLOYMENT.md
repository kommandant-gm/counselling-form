# Railway Deployment Guide

## Prerequisites

- GitHub account
- Railway account (free tier works perfectly)
- Git installed on your computer

---

## Step-by-Step Deployment

### 1️⃣ Create GitHub Repository

1. Go to [github.com](https://github.com) and log in
2. Click the **"+"** icon → **"New repository"**
3. Name it: `counselling-form`
4. Choose **Public** or **Private**
5. **DON'T** check "Initialize with README"
6. Click **"Create repository"**
7. Copy the repository URL (looks like: `https://github.com/YOUR-USERNAME/counselling-form.git`)

---

### 2️⃣ Push Code to GitHub

Open your terminal in the project folder and run:

```bash
# Initialize git
git init
git branch -M main

# Add all files
git add .

# Commit files
git commit -m "Initial commit: Counselling form application"

# Connect to your GitHub repo (replace YOUR-USERNAME)
git remote add origin https://github.com/YOUR-USERNAME/counselling-form.git

# Push to GitHub
git push -u origin main
```

✅ Your code is now on GitHub!

---

### 3️⃣ Deploy to Railway

#### Create Railway Account

1. Go to [railway.app](https://railway.app)
2. Click **"Login"**
3. Select **"Login with GitHub"**
4. Authorize Railway to access your repositories

#### Deploy Project

1. Click **"New Project"**
2. Select **"Deploy from GitHub repo"**
3. Choose your `counselling-form` repository
4. Railway will automatically detect it's a Laravel project

#### Configure Environment Variables

Railway will auto-generate some variables. You need to add these:

1. Click on your project
2. Go to **"Variables"** tab
3. Click **"Add Variable"** and add each of these:

```env
APP_NAME=Counselling Form
APP_ENV=production
APP_DEBUG=false
DB_CONNECTION=sqlite
ADMIN_PASSWORD=your-secure-password-here
```

**IMPORTANT**: Change `your-secure-password-here` to a strong password!

Railway auto-generates these (don't change):
- `APP_KEY` - Auto-generated by Railway
- `APP_URL` - Will be your Railway domain

#### Wait for Deployment

1. Railway will automatically:
   - Install Composer dependencies
   - Run database migrations
   - Start the application

2. Watch the **"Deployments"** tab for progress

3. Once complete, you'll see "Success" ✅

---

### 4️⃣ Get Your Live URL

1. In Railway dashboard, click **"Settings"**
2. Scroll to **"Domains"**
3. Click **"Generate Domain"**
4. You'll get a URL like: `https://counselling-form-production-xxxx.up.railway.app`

🎉 **Your app is now live!**

## Common Issues & Solutions

### Issue: "500 Server Error"

**Solution**: Check Railway logs

1. Go to Railway dashboard
2. Click your project
3. Click **"Deployments"**
4. Click the latest deployment
5. Check the logs for errors

Common causes:
- Missing `APP_KEY` - Railway should auto-generate this
- Database migration failed - Redeploy to retry

---

### Issue: Admin Password Not Working

**Solution**: Double-check environment variables

1. Go to Railway → **"Variables"**
2. Verify `ADMIN_PASSWORD` is set
3. Make sure there are no extra spaces
4. Click **"Redeploy"** after changing

---

### Issue: Slots Not Appearing

**Solution**: Check browser console

1. Open your browser's Developer Tools (F12)
2. Go to **"Console"** tab
3. Look for JavaScript errors
4. If you see CSRF errors, redeploy the app

---

### Issue: Form Shows "Registration Closed"

**Solution**: Check the date logic

The form automatically closes after December 23, 2025. If you're testing before that date and it still shows closed:

1. Check your server timezone in Railway
2. Verify the dates in `app/Models/Booking.php`

## Changing Admin Password

### Method 1: Via Railway Dashboard

1. Go to Railway → **"Variables"**
2. Find `ADMIN_PASSWORD`
3. Click to edit
4. Enter new password
5. Save
6. App will automatically restart

### Method 2: Via Code

1. Edit `.env.example` (for documentation)
2. Push to GitHub
3. Update variable in Railway as shown above

## Custom Domain (Optional)

Want to use your own domain like `counselling.yourcompany.com`?

1. In Railway, go to **"Settings"** → **"Domains"**
2. Click **"Custom Domain"**
3. Enter your domain
4. Railway will give you DNS records to add
5. Add the DNS records in your domain registrar
6. Wait 5-60 minutes for DNS to propagate

## Database Backup

Railway's SQLite database is ephemeral but persists as long as the app is running. For important data:

### Export Bookings (Manual Method)

1. Go to admin dashboard
2. Click **"Print"** button
3. Save as PDF

### Automatic Backup (Advanced)

Add a scheduled command to export data daily - requires Railway Pro plan for cron jobs.
